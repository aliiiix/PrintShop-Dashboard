PRINTSHOP DASHBOARD v1

Files:
- dashboard.html
- dashboard.css
- dashboard.js

How to run:
1. Keep all three files in the same folder.
2. Open dashboard.html in a browser.
3. The dashboard currently works in DEMO mode.
4. It checks the PrintShop Render backend health endpoint.

Current UI:
- Overview
- Orders
- Accept / Reject / Mark Printed
- Shop Online / Offline control
- B/W and Colour price controls
- Printer/computer pairing screen
- Notifications panel
- Responsive phone layout

Important:
This version does NOT yet authorize a real computer, send real printer jobs,
store uploaded files, or receive real-time production notifications.
Those require the next backend/print-agent stages.

Backend:
https://printshop-q8id.onrender.com
